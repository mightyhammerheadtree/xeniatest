  - core/src/xenon_cpu.cc is a new implementation written for this project, using xenia-canary as a reference.

Additional files derived from xenia-canary (HLE export tables):
  - public/js/recomp/hle_tables.js is generated by tools/generate_hle_tables.py from the
    xboxkrnl/xam/xbdm export tables in xenia-canary (canary_experimental branch).
    Only the ordinal → export-name mappings are carried over; the table data is a
    factual list of Microsoft Xbox 360 OS export ordinals and names as catalogued
    by a BSD-3-licensed open-source project. No Microsoft code is included.
  - public/js/recomp/xex_loader.js and public/js/recomp/hle.js are new implementations
    written for this project; xenia-canary's cpu/xex_module.cc, kernel/util/xex2_info.h
    and the kernel export tables were used as references. The retail XEX2 container
    key (20 B1 85 A5 9D 28 FD C3 40 58 3F BB 08 96 BF 91) is a public constant that
    ships in xenia's source; it is a format constant of the XEX container, not a secret.
  - public/js/recomp/aes.js is a from-scratch AES-128 implementation (ECB/CBC) for
    container decryption; it shares no code with any Microsoft or third-party library.
